# yamusic-to-ytmusic

Перенос библиотеки песен из Яндекс музыки в Youtube Music с последующим прослушиванием

## Зачем

Часть треков в Яндекс музыке стала недоступна, решил попробовать другую площадку, а заодно - разобраться с API.

## Как работает

1. `yaexport.py` выгружает лайкнутые треки из Яндекс Музыки в `likes.json`:
   название, исполнители, версия и длительность.
2. `yt_search.py` ищет каждый трек в YouTube Music и берёт первые 5 результатов.
   Результат засчитывается, только если совпали все три признака:
   - исполнитель (сначала ищется точное совпадение, потом похожее);
   - название (нечёткое сравнение);
   - длительность (разница не больше 3 секунд).
   Если среди песен ничего не подошло, поиск повторяется по видео.
   Найденное сохраняется в `matches.json`, не найденное в `suspicious.json`.
3. `yt_import.py` создаёт в YouTube Music плейлист и добавляет в него найденные треки. <...>

Принцип: лучше не перенести трек, чем перенести не тот.

## Известные ограничения

- Трек, у которого в Яндексе название транслитом, а на YouTube кириллицей не находится. в обратную сторону то же самое.
- Если на YouTube другая редакция трека (длиннее/короче больше чем на 3 с),
  он не переносится, даже если это та же песня.
- Треки, заблокированные на YouTube, перенести нельзя.

## Установка и запуск

Для поиска нужен доступ к YouTube.

```
git clone https://github.com/CastoMayz/yamusic-to-ytmusic.git
cd yamusic-to-ytmusic
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Получить токен Яндекс Музыки (откроется ссылка, на ней нужно ввести код):

```
python get_token.py
```

Создать файл `.env` и записать в него токен:

```
YM_TOKEN=ваш_access_token
```

Запуск:

```
python yaexport.py     # выгрузка лайков в likes.json
python yt_search.py    # поиск в YouTube Music → matches.json и suspicious.json
```

## Статус

Работает выгрузка, поиск и импорт. В моей библиотеке переносится 160 из 181 трека.
